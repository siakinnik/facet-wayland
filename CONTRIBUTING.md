# Contributing

Thank you for wanting to improve Facet. Bug reports, ideas and pull requests
are welcome.

## Contributor License Agreement

Before a pull request can be merged, you need to sign the
[Facet Contributor License Agreement](https://github.com/siakinnik/facet-core/blob/main/CLA.md).
In short: you keep the copyright to your code, but you allow the maintainer to
use it in any way, including under other licences (also proprietary ones) and
without naming you. Please read the full text; it is short.

A bot comments on your first pull request. To sign, reply with:

    I have read the CLA Document and I hereby sign the CLA

You only sign once; it covers all your later contributions to all Facet
projects. If the bot asks again in another Facet repository, post the same
comment there.

## Pull requests

- Keep a pull request to one change, and describe what it does and why.
- Code, comments and strings are in English; translations live only in the
  `i18n` files.
- If you add code, images or fonts written by someone else, name the source,
  the author and the licence in the pull request.
- Make sure the project builds and its tests pass.
